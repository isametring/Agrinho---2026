# Agrinho---2026
🌱 Agro Forte - Futuro Sustentável

O Agro Forte é um site institucional desenvolvido em HTML e CSS que apresenta uma proposta de agricultura sustentável, equilibrando produção agrícola e preservação ambiental.

📌 Sobre o Projeto

Este projeto tem como objetivo simular a presença digital de uma empresa do setor agrícola focada em sustentabilidade. Ele apresenta informações sobre:

A empresa e sua missão
Processos de produção agrícola
Práticas de sustentabilidade
Formas de contato
🚀 Tecnologias Utilizadas
HTML5
CSS3 (arquivo externo style.css)
Google Fonts (Roboto)
📁 Estrutura do Projeto
/
├── index.html
├── style.css
└── README.md
🧭 Seções do Site

O site é composto pelas seguintes seções:

Header (Cabeçalho)
Contém o nome da empresa e o menu de navegação.
Hero Section
Destaque inicial com slogan e botão de chamada para ação.
Sobre Nós
Apresenta a missão e os objetivos do Agro Forte.
Produção
Explica o uso de tecnologias para otimizar a produção agrícola.
Sustentabilidade
Mostra práticas ambientais adotadas pela empresa.
Contato (Footer)
Informações de contato e direitos autorais.
💻 Como executar o projeto

Faça o download ou clone este repositório:

git clone https://seu-repositorio-aqui.git
Abra o arquivo index.html em qualquer navegador.

Pronto! O site estará funcionando localmente.
